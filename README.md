# Redução de Custos AWS - Farmácia

Repositório contendo o relatório de implementação de serviços AWS para a ABC Indústrias de Fármacos.

- `relatorio-implementacao-servicos-aws.md`: relatório completo com as etapas de adoção de serviços AWS para redução de custos.

## Objetivo

Apresentar uma proposta de implementação de serviços AWS que visa:

- reduzir custos de armazenamento e arquivamento;
- otimizar recursos computacionais com desktops virtuais e instâncias Spot;
- monitorar e controlar gastos com CloudWatch e Cost Explorer.
